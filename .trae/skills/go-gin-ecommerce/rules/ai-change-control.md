# AI 修改现有代码强制规则
1. 先读现有 Router、Handler、Service、Repository、Model、DTO、Migration 与相关规则，禁止臆造现有实现。
2. 先明确修改范围；交易、资金、鉴权、数据库变更需简述影响和风险。
3. 最小范围修改；未经授权禁止重构其他模块、改公共 API 契约、删除字段、修改已执行的 Migration。
4. 禁止绕过鉴权、支付验签、事务、唯一约束和幂等；禁止信任客户端价格。
5. 未经核实禁止杜撰有赞 API；涉及价格、积分、佣金未确认规则必须先询问。
6. 不擅自引入 MQ、微服务、CI/CD、压测和部署系统。
7. 新增表与每字段中文 COMMENT，关键代码中文注释，DTO 与 Model 分离。
8. 交付说明变更文件、接口/数据库影响、实际验证结果、未验证事项和人工待确认项；不得虚报验证通过。
