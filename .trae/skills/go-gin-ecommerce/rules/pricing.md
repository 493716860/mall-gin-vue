# 统一价格计算（强制）
所有商品、订单应付金额必须由服务端计算，客户端仅提交商品/SKU、数量、优惠选择等意图。金额统一整数分，比例使用整数基点或定点计算并定义舍入方式。统一 `PricingService` 计算链：商品实时有效价 → 会员折扣 → 营销优惠（按规则可叠加）→ 积分抵扣 → 运费 → 应付金额；实际顺序需在项目中唯一配置并固化，不允许不同入口重复实现。订单明细保存原价、会员等级/折扣、活动与券分摊、积分抵扣、运费分摊、实付及佣金计算基数快照；订单总金额等于明细汇总与费用调整。定义商品排除规则、最低应付额、券使用范围、积分上限、退款按原明细比例/金额回退规则。分销佣金不得以客户端价格计算。优惠、积分、佣金规则变更不应改写历史订单。
