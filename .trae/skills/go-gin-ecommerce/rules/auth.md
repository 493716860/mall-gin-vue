# 统一认证授权
统一 Auth 中间件负责 Token 验证、有效期、撤销状态、账号状态、主体类型/audience。小程序用户和后台管理员身份隔离，禁止跨端 Token 混用。公开路由显式白名单，其余默认要求登录；管理员接口按 RBAC 校验操作权限；用户订单、地址等必须做资源归属校验。后台密码使用可靠密码哈希算法；退出登录使 Token/会话失效。权限判断不可仅依赖前端隐藏按钮。

## JWT 技术约束
使用 golang-jwt，明确签名算法白名单、密钥来源、iss/aud/sub/exp/nbf 等声明校验；拒绝 alg 混淆，Token 撤销和退出登录须由服务端会话状态或等效机制实现。Redis 可按需保存会话与撤销信息，但不作为唯一的订单事实来源。
