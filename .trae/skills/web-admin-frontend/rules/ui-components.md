# Element Plus 页面与组件规范（P0）
## 列表与筛选
筛选参数与分页状态分离，筛选条件变化时重置页码；分页/排序/筛选/刷新请求统一入口，避免重复加载与旧请求覆盖新结果。保留 loading、空态、失败重试。查询条件是否缓存由产品体验要求决定。
## 表单与弹窗
Element Plus Form 负责交互校验，后端仍负责最终校验。表单模型与 API DTO 分离，通过显式映射转换日期、枚举、数组和 ID；禁止直接提交含 UI 临时字段的整个表单对象。提交中禁用重复提交；弹窗打开按新增/编辑场景初始化数据，关闭时按需 resetFields/clearValidate，避免跨记录数据残留。保存成功后按需刷新来源列表，不无条件重置用户筛选。
## 详情、上传与反馈
详情页明确加载/不存在/无权限/失败状态；上传统一校验格式、大小、数量，上传凭证和下载链接按实际后端契约处理。反馈区分成功、可恢复错误和服务端错误；禁止多处重复弹同一错误提示。
## 复用边界
优先原生 Element Plus。仅当交互模式稳定重复时抽取组件；不构建配置项泛滥的万能表格、万能表单。公共组件只依赖 Props/Emits，不耦合具体业务 Store。
