# Vue Router 4 动态路由与权限（P0）
公开路由白名单明确；登录状态初始化完成后再进行受保护路由判断，防止刷新瞬间误跳登录。后端授权菜单映射到前端预定义组件白名单，禁止把服务端任意路径直接 import 为代码。动态路由按账号加载一次，刷新时恢复，切换账号/退出登录清除动态路由与用户菜单缓存。
导航守卫处理 401/403/404、未授权访问、目标回跳与重定向循环。路由 params/query 做类型和范围校验，禁止在 URL 传 Token/密钥。按钮权限通过统一指令或 composable 实现，仅控制展示；真正 RBAC 与数据权限必须由后端执行。动态路由权限变化时及时刷新或失效。
