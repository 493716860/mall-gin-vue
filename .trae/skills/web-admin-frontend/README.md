# web-admin-frontend V2.0 企业级工程规范
技术栈：Vue 3 Composition API + Vite + TypeScript + Element Plus + Pinia + Vue Router 4 + Axios + ECharts + ESLint + Prettier。
只约束架构、代码风格、组件、路由权限、状态、请求、图表、安全与可维护性，不定义业务功能。产品需求以独立产品原型设计 Skill 和经确认的需求文档为准。
## 使用
本目录可单独检出并部署；读取 SKILL.md 和相关 rules/，不要直接覆盖已有项目 AGENTS.md。
## V2.0 强化
Element Plus 标准页面模式、动态路由/权限/缓存、Axios 错误模型与并发、Pinia 状态边界、组件抽象与 AI 变更审查。
