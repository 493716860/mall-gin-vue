# 复杂 API 设计（P0）
幂等：写明幂等键来源、作用域（用户/接口/业务）、有效期、请求指纹、重复请求返回行为及唯一约束；避免依赖前端防连点。批量操作：明确全成功/原子失败/逐项部分成功语义与错误明细，不混用。异步操作：返回受理标识及可查询状态，明确超时与最终结果。分页：默认页大小、最大页大小、排序白名单和稳定顺序；避免无限量返回。资源冲突使用 HTTP 409，校验错误与业务前置条件失败分别约定错误码。API 兼容：新增可选字段优先，删除/重命名/语义变更需版本与迁移计划。微信支付等外部回调按官方协议定义，不能强套普通 JSON Envelope。OpenAPI operationId 唯一，字段说明、示例、鉴权与错误响应完整。
