# 示例订单状态机
| 当前状态 | 事件 | 条件 | 下一状态 | 异常处理 |
|---|---|---|---|---|
| 无订单 | 创建订单 | 请求有效、库存可用、幂等键未创建 | PENDING_PAYMENT | 失败不落库 |
| PENDING_PAYMENT | 支付成功通知 | 验签、商户号/订单/金额一致，且未处理 | PAID | 重复通知幂等 |
| PENDING_PAYMENT | 超时取消 | 与支付状态确认无冲突 | CANCELLED | 释放预占库存 |
| PAID | 重复支付通知 | 同一平台交易 | PAID | 返回已处理 |
| CANCELLED | 迟到支付通知 | 外部已支付 | 待人工/退款补偿 | 不得直接改成 PAID |

本表为简化示例，支付、退款和取消竞态需另行完成 L3 详细设计后才能用于生产。
